# 1010:0390 PLAYSET_DLG_PROC
Status: understood · Cluster: dialogs · Convention: Pascal far (dialog procedure)

**Purpose (confirmed):** Dialog procedure of the play-settings window: speech/subtitle options, video and CD speed options, music and sound switches and the two volume sliders.
**Inputs:** The standard dialog arguments (scroll messages arrive as 0x114 with the bar's window in `param_2`).
**Outputs / state written:** Initialise: remembers the current volumes (`DS:0068` digital, `DS:006a` music) in `DS:2d68`/`2d66`, sets both sliders (range 0 to 255, position = volume / 256; the digital slider is disabled when no wave device was opened, `DS:004a` = 0), ticks the check boxes (skip transitions 0x2cc, digital sound off 0x2ca, music off 0x2ce) and the radio groups (read speed 0x2be to 0x2c1 from `DS:0064`, video size 0x2e4 to 0x2e6 from `DS:0066`, dialog option 0x3d4 to 0x3d6 from `DS:004c`, MIDI type 0x14a to 0x14b from `DS:004e`) and gives the focus to control 2 (Cancel). OK (1): copies each group's selection back into those variables (defaults 0x2be, 0x2e4, 0x3d6, 0x14a), the skip box into `DS:0050`, and calls `1000:1d1a(0)` or `1000:1c36(0)` when the music or sound check box no longer matches the state; if sound ended up off and the dialog option is 0x3d5 it becomes 0x3d6. Cancel (2): restores the saved volumes and re-applies them to the wave and MIDI devices. Both close with 1. Scroll messages: the volume byte changes by -1 or +1 for the arrows and by -5 or +5 for page clicks (`1010:0b72`), jumps to 0 or 255 for the ends and to the thumb position when dragged; each change sets the volume at once (`waveOutSetVolume` for the digital bar, `midiOutSetVolume` for the music bar, same value in both channels).
**Calls:** `1010:0b72`, `1000:1d1a`, `1000:1c36`, `MCIGetDeviceID`, `waveOutSetVolume`, `midiOutSetVolume`, dialog and scroll-bar calls.
**Yields / blocks / timing:** Modal; blocks the caller.
**Edge cases:** Volumes are kept as 16-bit values whose high byte is the slider position. The settings are only written to the settings file when the game window closes.
