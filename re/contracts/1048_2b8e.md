# 1048:2b8e inferred_enter_room
Status: understood · Cluster: script and rooms · Convention: cdecl far, caller cleans

**Purpose (confirmed in outline):** Load a room: its glue file, text file, objects, music, backdrop, palette, sprites and walk map, and set up the scene.
**Inputs:** The window and the room number.
**Outputs / state written:** Sets the current room (`DS:007c`), clears `DS:005a`, frees the credits picture if loaded, frees all sounds (`10a8:03e2`), clears the table of shared sprite records and allocates the first two (0x44 bytes each, used for the player and its mirror). Loads the glue file `GL00_%X%02d.000` (room / 100, room mod 100) (`1088:003e`) and the room text file (`1048:1f6e`), parses the room's objects (`1048:093e`), starts the first music entry whose conditions are true (`10a8:0a1e`), loads the backdrop picture (`1080:0890`), imposes the fixed palette (`1028:00b6`), copies the palette to `DS:9798`, resets the colour table of the picture to indexes 0 to 255 and makes the palette (`1080:0ad6`). Empties the scene lists (`1078:03be`), resets the two player sprites (`1078:0106`: flags, and for the second a default clip rectangle 380, 146, 420, 251) and sets the scene clip (`1078:00ca`). For each sprite node: if its `LoadCond=` list exists and is false the node is removed and freed; otherwise each frame whose sequence entry is above 0 is loaded through the image cache (`1070:0000`) by the node's name plus the frame number, the frame's x and y default to the picture's width and height when 0, the node gets a sprite record (an own record when the sprite index is 100, else the shared record of that index, created on first use) with its flags (bit 1 mirrored, bit 3), and a scaled-picture record when it is flagged for scaling. Finally loads the walk map picture and copies it, bottom row first, into the room record's grid at +0x52 with row stride 80 and an 8-cell border on both sides repeating the edge value.
**Calls:** `10a8:03e2`, `10a8:0a1e`, `1088:003e`, `1048:1f6e`, `1048:093e`, `1028:00b6`, `1080:0890`, `1080:0ad6`, `1078:03be`, `1078:0106`, `1078:00ca`, `1060:07f6`, `1060:07a8`, `1070:0000`, `1090:0000`, `1090:0068`, `1038:01a4`.
