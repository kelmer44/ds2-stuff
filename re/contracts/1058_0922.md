# 1058:0922 inferred_hit_test_click
Status: understood · Cluster: clicking · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Find which object the pointer is over and start the action of the chosen verb (confirmed).
**Inputs:** Window, mouse x, mouse y, verb (0 go, 1 use, 2 look).
**Outputs / state written:** Stores the pointer in `DS:5e10/5e12`. Walks the list of room objects (head `DS:5cbe/5cc0`, next far pointer at object +0xc/+0xe): an object is hit when x is between its rectangle's left (+0) and right (+4) and y between top (+2) and bottom (+6) and its disabled word (+8) is 0. The verb picks the head of the action list: verb 0 object +0x18/+0x1a (the `GoStart` section), verb 1 +0x14/+0x16 (`UseStart`), verb 2 +0x10/+0x12 (`LookStart`). In rooms 0x13a and 0x32b a go click with no go list uses the use list. The action records are chained at +0x93/+0x95; the first record whose condition list is true (`inferred_test_any`) is run: a variable is set (call to `1060:0b26`) and `inferred_run_object_action` is called with it; its result is returned. When no object matches, or the object has no true record, nothing runs; for verb 1 the item cursor is reset to `cUseIt` (the held inventory item is put away: `1008:0e16`, `1008:0000`) and 0 is returned.
**Calls:** `1060:07f6`, `1060:0b26`, `1058:01e0`, `1008:0e16`, `1008:0000`, `LoadCursor`.
**Yields / blocks / timing:** none
**Edge cases:** Only the topmost object in list order that is hit AND has a true record counts: if an object is hit but has no true record the search goes on with the next object. Rectangles are inclusive.
