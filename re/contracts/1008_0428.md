# 1008:0428 DLG_INVENTORY
Status: understood · Cluster: main window and input · Convention: Pascal far (dialog procedure)

**Purpose (confirmed in outline):** The dialog procedure of the inventory bar: a 640 by 70 window along the bottom of the screen that shows the player's items and lets them be scrolled and used.
**Inputs:** The standard dialog arguments (window, message, wParam, lParam; the mouse x is the low word of lParam).
**Outputs / state written:**
- Initialise (0x110): creates a brush for the background, then, if the picture header template (`DS:1fce`) exists, opens the bar with `1008:0af6`, remembers the window, sets the cursor with `1008:0000`, and moves the window to y = 410, 640 by 70, shown without changing stacking order, with no focus. Without the template it closes at once with result 1.
- Paint (0xf): draws the whole bar with `1008:02a2`. Background colour request (0x19): transparent text mode, returns the brush.
- Commands 1 and 2, and the private message 0x400: free everything (`1008:0a58`) and close with result 1. Other commands return 1. System commands such as move and size are swallowed.
- Mouse move (0x200): stores the pointer in `DS:3c54`/`3eb0`; between x = 80 and 559 sets the item cursor (`1008:004c`), otherwise the arrow cursor (`1008:00b6`).
- Button down (0x201, double click 0x203): if a wait counter `DS:008a` is above 0, ends it and repaints the screen behind the bar (`1078:1238`, `10a8:0042`). Left of x = 80 with items scrolled off: sets the left-arrow pressed flag `DS:0d28` and redraws that arrow; from x = 560 with more than 10 items past the scroll position: the right-arrow flag `DS:0d2a`; elsewhere between: sets the item-pressed flag `DS:0d2c`.
- Button up (0x202): a left-arrow release scrolls the bar one item to the left, a right-arrow release one item to the right (only while more than 10 items remain), each redrawing the whole bar. An item release (item index `(x - 70) / 50` plus the scroll position, inside the item count) acts according to the cursor mode `DS:770e`: mode 1 runs the item's list at +0x14, mode 2 the list at +0x10: each list is a chain of records (next at +0x93); the first record whose conditions are true (`1060:07f6`) is run with `1058:01e0`. In mode 1 with no match, `1008:0e16` puts the \"Have\" items back and the use cursor `cUseIt` is loaded into `DS:8722`. The cursor is reset (`1008:0000`) and the pressed flags are cleared.
- Right button (0x204): steps the cursor mode through 0, 1, 2 and sets the cursor.
- Keys: key down (0x100) is passed to `1000:12be`; key up (0x101) resets the pointer step to 2; the system key down (0x104) moves the pointer with the cursor keys, number-pad 8/2/4/6 and I/K/J/L, and Space posts a right-button message; system key up of Enter (0x105) posts a left button down and up at the pointer. Window position messages (0x46, 0x47) return 1.
**Calls:** `1008:0af6`, `1008:0a58`, `1008:02a2`, `1008:00d6`, `1008:01b8`, `1008:0000`, `1008:004c`, `1008:00b6`, `1008:0e16`, `1000:12be`, `1058:01e0`, `1060:07f6`, `1078:1238`, `10a8:0042`, Windows dialog, GDI and cursor calls.
**Yields / blocks / timing:** Runs as a modal dialog; the caller (`WINPROC`) waits until it ends.
**Edge cases:** The item hit test uses 70 as the start of the first item but the cursor test uses 80; an item whose index is outside the item count does nothing. A press in the item area is only acted on when the matching release is also there.
