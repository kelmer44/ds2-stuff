# 1000:1c36 inferred_toggle_digital_sound
Status: understood · Cluster: main window and input · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Switch digital sound (speech and effects) off or on again, optionally showing a message that says which.
**Inputs:** One int: non-zero to show the message.
**Outputs / state written:** Flips `DS:005c` (1 = sound on). Turning off: if `DS:004c` is `0x3d5` it becomes `0x3d6`, and `10a8:0000` is called with 0. Turning on: `DS:004c` becomes `0x3d4`, the WaveMix channel set `DS:004a` is flushed, the wave device's volume is set to `DS:0068` and `10a8:0000` is called with 1. With the message flag set it shows "Sin Sonido Digital" or "Con Sonido Digital" the same way as the music toggle.
**Calls:** `10a8:0000`, `WaveMixFlushChannel`, `MCIGetDeviceID`, `waveOutSetVolume`, `1098:0248`.
**Yields / blocks / timing:** none
**Edge cases:** `DS:004c` is the dialog option of the play-settings window (radio buttons 0x3d4 to 0x3d6).
**Evidence:** `re/export/fn/1000_1c36.c`; callers the game window (`1000:12be`) and the play-settings dialog.
