# 10a8:02e2 inferred_cache_sound
Status: understood · Cluster: audio and video (MCI, WaveMix) · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Add a loaded sound to the effect cache when its name starts with `SE`.
**Inputs:** A far pointer to the name and the far pointer to the sound data.
**Outputs / state written:** If the name starts with `S` and `E` (any case) and fewer than 20 entries exist, stores the name (9 bytes) and the data pointer and raises the count `DS:2790`.
**Calls:** `lstrcpy`.
**Yields / blocks / timing:** none
**Edge cases:** Other names (speech, music) are never cached. A full cache silently ignores the sound.
