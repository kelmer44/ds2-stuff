# 1068:1692 inferred_next_conv_token
Status: understood · Cluster: conversations · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Read the next line of a conversation script (`CONVnnnn.TXT`) and return its keyword code and cleaned value.
**Inputs:** `[bp+6]` near pointer to a buffer that receives the value text.
**Outputs / state written:** Reads from the script buffer (far pointer `DS:3424/3426`, position `DS:3422/3424`, end `DS:3428/342a`), advancing the position past the newline; counts lines in `DS:1db8`. Returns 0xff at the end of the file, 0xfe for a line with a key but no recognised word or an empty key, 0 for a two-character line (empty), otherwise the keyword code: `CONVERSATION` 1, `DECLARE` 2, `IMPORT` 3, `NODE` 4, `FALLTHROUGH` 5, `ENTRY` 6, `HIDE` 7, `UNHIDE` 8, `TEXT` 9, `GOTO` 10, `ASSIGN` 0xb, `DESTROY` 0xc, `MESSAGE` 0xd, `MESSAGESTOP` 0xe, `SPEAKER` 0xf. The value is what follows the `=`: for every key except `SPEAKER` only characters above a space and below `{` are kept (so spaces and non-ASCII characters are removed: `goto = (GothMission) Brought` becomes `(GothMission)Brought`); for `SPEAKER` spaces are kept only after the comma once text has started (`0, Mike` becomes `0,Mike`). Everything from a `;` is dropped first. The key is upper-cased and ends at the first character that is not a letter, digit or underscore.
**Calls:** `1060:0000` (upper-case), `lstrcpy`, `lstrcmp`.
**Yields / blocks / timing:** none
**Edge cases:** A keyword that is not in the list gives 0xfe, which the callers skip. Lines over about 500 characters overflow the stack buffer. The two characters removed at the end of each line are CR LF.
**Evidence:** `re/export/fn/1068_1692.c`; the keyword strings at `DS:1ecf` to `DS:1f3b`; all 51 conversation files use only these keywords (plus `;` comments).
