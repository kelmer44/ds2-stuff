# 1000:1b0e inferred_parse_command_line
Status: understood · Cluster: main window and input · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Read the Windows command line, act on the `/x` and `-x` options and give back the text with the options removed.
**Inputs:** Far pointer to the command-line text (also used as the output buffer).
**Outputs / state written:** Reads word by word with `1000:1a98`. Words starting with `/` or `-`: `s` followed by `t`, `c` or `w` sets `DS:0050`, `DS:0052` or `DS:0054` to 1; `d` followed by `a` sets `DS:3ca6`, `3ca8`, `3caa`, `3cac` to 1, followed by `m` sets `DS:0056`; `p` followed by a digit sets `DS:0062` to that digit. Any other word is copied to the front of the same buffer, separated by single spaces, and the string is ended with a zero. Returns the pointer where scanning stopped.
**Calls:** `1000:1a98`, stack-check helper `10d0:029e`.
**Yields / blocks / timing:** none
**Edge cases:** Option letters are lower-case only. Unknown options are dropped silently. A trailing option letter without a second letter sets nothing.
**Evidence:** `re/export/fn/1000_1b0e.c`; its only caller is the start-up function `1000:0034`.
