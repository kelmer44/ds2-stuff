# 1058:01e0 inferred_run_object_action
Status: understood · Cluster: clicking · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Walk the player to an object's position if needed, then run an action record: sounds, subtitles, a conversation, a picture, a video, variable changes (confirmed in outline).
**Inputs:** Window, a far pointer, the far pointer of the action record, the verb (0, 1, 2).
**Outputs / state written:** Clears the pending-continuation words `DS:008c/008e`, copies the pointer position. **Standing at the spot:** if the record's x and y (+4, +6) are both 0 and its direction (+0xa) is 8 (no walk needed), or the player is within 10 pixels of that x and y in both axes and facing the direction (`DS:8e3c` equals +0xa), the action runs now; **otherwise** (if a variable allows walking) the player is sent to the spot: the path is cleared, the next point and facing set, `inferred_start_walk` is called, the pending record, verb and position are stored (`DS:008c/008e`, `DS:0094`, `DS:0086/0088`) and the function returns; the game window procedure calls it again when the player has arrived. **Running the action:** music `Midi=` (+0x38) is started; a conversation (+0x6e) is started through the conversation routines in segment `1068`; a `Cursor=` (+0x2b) replaces the use cursor; a video (name at +0x14) is skipped when the skip option is set and its name starts with `T`, or in room 0x5dd when a flag is set; otherwise it is played through MCI (`open ... type avivideo alias vfw`, window or full-screen rectangle from +0x21..+0x27, `play vfw ... notify` and `DS:0368` = 1 while it plays; or `play ... wait` then stop and close when it is not full size); with no picture (+0x45): effect (+0x52) and speech (+0x5f) sounds, the speech with a subtitle when text was loaded (+0x10/+0x12); with a picture: it is loaded, drawn over the screen, the sounds play and a variable is set; then the `Change=` list (+0x7b) is applied. Finally, for verb 2 or a record whose +8 is 0: the wait-until list (+0x8f/+0x91) is stored as the pending continuation with verb and pointer, and for verb 1 with neither a wait list nor a cursor the item cursor is reset to `cUseIt`; otherwise a variable is set. Returns 1.
