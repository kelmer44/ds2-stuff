# 1060:0188 inferred_next_word
Status: understood · Cluster: game variables · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Take the next word off the front of a string (confirmed).
**Inputs:** `[bp+6]` near pointer to the text, `[bp+8]` near pointer to the output buffer.
**Outputs / state written:** Skips spaces and commas, copies characters while their class (`DS:5d0e`) has any of the bits 1, 2, 4 or 8 (letters, digits, `_`, `!` and the operator characters `+ - * / = & | ( )`), terminates the copy and shifts the rest of the text to the front. A character with class 0 (for example `.` or `;`) or the delimiters (space, comma, tab, NUL) end the word.
**Calls:** `lstrcpy`.
**Yields / blocks / timing:** none
**Edge cases:** Differs from `inferred_next_token` only for characters of class 0, which end this word but not that token. Used before every number or name read in the section parsers.
