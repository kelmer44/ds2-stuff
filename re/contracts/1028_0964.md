# 1028:0964 inferred_speed_up_system_timer
Status: understood · Cluster: resource layer · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Double the PC timer's tick rate and the double-click time on Windows 3.x.
**Inputs:** none
**Outputs / state written:** Reads the double-click time into `DS:64f6`; if it is below 0x4dac milliseconds it is doubled. Then writes the PC timer chip directly (ports 0x43 and 0x40) with a count of 0x8000 instead of 0x10000, so the system tick runs twice as fast. Returns 0x80.
**Calls:** `GetDoubleClickTime`, `SetDoubleClickTime`, port output.
**Yields / blocks / timing:** none
**Edge cases:** Direct hardware access: a port must replace it with an ordinary timer.
