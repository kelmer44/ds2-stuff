# 1070:0000 inferred_image_cache_get
Status: understood · Cluster: graphics and sprites · Convention: cdecl far (flags byte, name far pointer)

**Purpose (confirmed):** Get a loaded image record by name, loading it the first time and counting uses (confirmed).
**Inputs:** Name far pointer (without extension) and a flags byte.
**Outputs / state written:** Searches a linked list (head at `DS:1fc8/1fca`) of 0x17-byte nodes (name at +0, image record far pointer at +0xd, use count at +0x11, next far pointer at +0x13) with a case-insensitive compare. A hit adds 1 to the use count and returns the record. A miss allocates a node and a 0x18-byte image record, loads the picture with `inferred_load_image` (adds `.BMP`) and fills width, height and the placement words with `inferred_read_image_header`; when bit 0 of the flags is set the record's far pointer at +0x14 is set to the record itself. The node goes to the front of the list.
**Calls:** `lstrcmpi`, `lstrcpy`, `1090:0000`, `1080:0890`, `1080:0ad6`.
**Yields / blocks / timing:** none
**Edge cases:** Returns only the offset word of the record pointer, so the record's selector must be implied by the caller. The image record is 0x18 bytes: the words at +0x14/+0x16 are a far pointer that is only set by the flag.
