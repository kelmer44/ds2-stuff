# 10a8:0446 inferred_load_sound
Status: understood · Cluster: audio and video (MCI, WaveMix) · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Load a named sound into a slot and hand it to the mixer.
**Inputs:** The glue table, a far pointer to the sound name and a far pointer to the slot.
**Outputs / state written:** Frees whatever the slot held, builds `name.WAV`, and sets the slot's data pointer: 0 when digital sound is off, the dialog option is the text-only one (0x3d6) or there is no mixer session; otherwise from the effect cache or by loading the resource (`1098:0326`) and caching it (`10a8:02e2`). Stores the size of the resource (`1088:0892`) at +4, builds a 66-byte wave description and opens it in the mixer (`WaveMixOpenWave`), keeping the handle at +8. Returns 1.
**Calls:** `10a8:0350`, `10a8:028e`, `10a8:02e2`, `1098:0326`, `1088:0892`, `WaveMixOpenWave`, `lstrcpy`, `lstrcat`.
**Yields / blocks / timing:** none
**Edge cases:** With no data the wave is still opened with an empty description (the mixer then fails quietly).
