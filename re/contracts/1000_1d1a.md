# 1000:1d1a inferred_toggle_music
Status: understood · Cluster: main window and input · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Switch the MIDI music off or on again, optionally showing a message that says which.
**Inputs:** One int: non-zero to show the message.
**Outputs / state written:** Flips `DS:005e` (1 = music playing). Turning off: sets the sequencer's output volume to 0 and sends `stop midifile` to MCI. Turning on: sets the volume to `DS:0068` in both channels and sends `resume midifile`. With the message flag set, builds "Sin Música" or "Con Música" in the shared text buffer `DS:37f0` and shows it through `1098:0248` (message box).
**Calls:** `MCIGetDeviceID`, `midiOutSetVolume`, `mciSendString`, `1098:0248`.
**Yields / blocks / timing:** none
**Edge cases:** The volume value is not clamped here. The message is the Spanish build's text.
