# 1078:0172 inferred_begin_rect_buffer
Status: understood · Cluster: graphics and sprites · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Create the temporary off-screen buffer (a WinG bitmap) in which one rectangle of the scene is composed (confirmed).
**Inputs:** `[bp+6..8]` scene far pointer, `[bp+a]` device context (not used), `[bp+c]` width, `[bp+e]` height.
**Outputs / state written:** Scene +10 = width, +12 = height. First call only: allocates the shared 0x428-byte DIB header (`DS:1fce/1fd0`: 0x28 header bytes then 256 colours); asks WinG for the recommended format and, if none, uses a 40-byte header, 1 plane, 8 bits, uncompressed; copies the 240 first colours of the game palette copy at `DS:6c9e`, reordered to blue, green, red. Every call: sets width and height (the height sign follows the recommended direction, so the buffer is bottom-up unless WinG recommends top-down), copies the last 16 palette entries, creates the WinG DC once (scene +8, selecting a stock object, old object saved at `DS:9f42`), creates the WinG bitmap (handle to scene +2, pixel pointer to `DS:343a/343c`) and selects it (old bitmap saved at `DS:76f6`). On failure shows "WinG can't allocate enough memory.", frees and exits.
**Calls:** `1090:0000`, `1090:0068`, `WinGRecommendDIBFormat`, `WinGCreateDC`, `WinGCreateBitmap`, `SelectObject`, `GetStockObject`, `1098:0248`, `10d0:01a3` (exit), `10d0:046e` (unread helper).
**Yields / blocks / timing:** none
**Edge cases:** The caller must delete the bitmap afterwards (every redraw path ends with `SelectObject(dc, old)` and `DeleteObject(scene +2)`), so a new bitmap is created per rectangle. The buffer is as wide and as tall as the rectangle, not as the screen.
