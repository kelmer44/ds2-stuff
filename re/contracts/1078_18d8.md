# 1078:18d8 inferred_update_sprite
Status: understood · Cluster: graphics and sprites · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Register a sprite's change (appeared, disappeared or moved) by adding its old and new rectangles to the scene's dirty rectangle (confirmed).
**Inputs:** `[bp+6..8]` scene far pointer, `[bp+a..c]` sprite far pointer, `[bp+e]` list number.
**Outputs / state written:** Cases: (1) no new image and an old image: removes the sprite from its list and uses the old rectangle (x, y from +0x22/+0x24, size from the old image +8/+10). (2) new image and no old image: adds the sprite to the list and uses the new rectangle. (3) both: uses the union of old and new rectangles. New top-left = `(image +0xc + sprite +0x2e, image +0xe + sprite +0x30)` is stored in +0x3e/+0x40. The rectangle is merged into the scene's dirty rectangle (+0x340 left, +0x342 top, +0x344 right, +0x346 bottom; +0x348 = 1 once set). Finally old := new: +0x1e/+0x20 = +0x2a/+0x2c, and if there is an image, +0x22/+0x24 = new top-left and +0x26/+0x28 = image width and height.
**Calls:** `1078:0806`, `1078:08c0`.
**Yields / blocks / timing:** none
**Edge cases:** Nothing is drawn here; the repaint happens in `inferred_redraw_rect`. A sprite with both images null does nothing.
