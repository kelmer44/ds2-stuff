# 1048:114a inferred_parse_sprite_section
Status: understood · Cluster: script and rooms · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Read the lines of a room file's sprite section (from `SpriteStart=` to `SpriteEnd=`) and build the room's list of animated sprite nodes.
**Inputs:** The room record (far).
**Outputs / state written:** Reads keyed lines with `1048:0b54` until code 0x2b (`SpriteEnd=`). Each line changes the current sprite node: **`Cond=`** (1) starts a new node (0x685 bytes, zeroed, appended to the list at room +0x39 or after the previous node's +0x681), sets its sprite index (+0x67b) to 100 and parses the condition terms into a new 24-byte list node at +0xd. **`Cond2=`** (0x15) adds another condition node chained after the current one (an alternative). **`LoadCond=`** (0x1a) and **`LoopCond=`** (0x1b) create condition lists at +0x11 and +0x15. **`Anim=`** (7) copies the animation name to +0. **`Effect=`** (4) and **`Speech=`** (5): an optional leading number (the frame at which to play, +0x45 or +0x54) then the sound name (+0x47 or +0x56). **`Change=`** (8) parses assignment terms into +0x1b. **`ChangeAt=`** (0x1d): a number (+0x43) then assignment terms into +0x2f. **`Status=`** (0xb): six numbers into +0x67 (flags, window low, window high, draw list, frame count, hold count). If the count is above 128 it shows "Too many frames in one animation!"; an empty sequence (+0x27b) is filled with 1 to count; if both start and end index (+0x63, +0x65) are 0 they become 0 and count - 1. **`Sequence=`** (0x11) parses a number list into +0x27b, **`PosX=`** (0x16) into +0x37b, **`PosY=`** (0x17) into +0x47b and **`ScaleVal=`** (0x18) into +0x57b (count = frame count, or 128 when not yet known). **`SpriteIdx=`** (0x12) is one number into +0x67b. **`LoopPoint=`** (0x1c) is one number into +0x63. All other keys are ignored (`StartIndex=` and `EndIndex=` are not used here).
**Calls:** `1048:0b54`, `1060:0652` (terms), `1060:0188`, `1060:0062`, `1060:0c44` (numbers), `1060:0d2e` (number lists), `1090:0000`, `1098:0248`, `lstrcpy`.
