# 1080:02f0 inferred_fade_to_black
Status: understood · Cluster: graphics and palette · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Fade the screen to black by stepping the palette down.
**Inputs:** A device context.
**Outputs / state written:** Reads the 256 system palette entries into `DS:6c9e`, selects the game palette, then 256 times: lowers every non-zero red, green and blue value by 1, marks the entries as animatable and calls `AnimatePalette` for entries 1 to 254.
**Calls:** `GetSystemPaletteEntries`, `SelectPalette`, `AnimatePalette`.
**Yields / blocks / timing:** Runs 256 palette updates in a row; takes a noticeable fraction of a second.
**Edge cases:** Entries 0 and 255 (black and white) are not animated. Nothing happens without the game palette (`DS:200a`).
