# 10b8:02b2 inferred_blit_rows_prefixed
Status: understood · Cluster: 32-bit bitmap helpers · Convention: 32-bit near/far code in a USE32 segment (Ghidra decodes it as 16-bit; read with `ne_segments.py dis --use32`)

**Purpose (inferred):** Copy rows of pixels from a source whose rows each start with a 4-byte header giving the stored length. The first bytes of this entry are the segment's start-up stub.
**Inputs:** Stack from `[bp+6]`: dword destination row gap, dword row count, dword row width in bytes, source far pointer, dword destination offset, destination selector word (callee pops 22 bytes).
**Outputs / state written:** Does nothing when the width or the row count is 0. For each row: skips the 4-byte header, copies `width / 4` dwords (at most the length word at header +2) and then `width mod 4` bytes to the destination, adds the destination gap (`gap - width`), and advances the source by the length word of the header. The code before `10b8:02dc` is the DPMI stub that sets the segment's 32-bit bit (`int 31h` functions 0Bh and 0Ch).
**Calls:** none
**Yields / blocks / timing:** none
**Edge cases:** The comparison mixes a dword count with a byte length, so rows shorter than `width` are cut at the length in dwords. No caller in the export.
