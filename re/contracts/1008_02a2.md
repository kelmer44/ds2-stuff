# 1008:02a2 inferred_draw_inventory_bar
Status: understood · Cluster: main window and input · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Build and show the whole inventory bar, 640 by 70 pixels.
**Inputs:** A device context for the window.
**Outputs / state written:** Selects the bar's memory bitmap and restores its saved background (44,800 bytes copied from `DS:2d62` into the bar's pixels). Draws up to 10 item images, from item `DS:8f98` on and no further than the item count `DS:0d26`, each at x = 70 + 50 × position and y = 10 (item records are 24 bytes apart). Draws the frame image over them, then the arrows as in the two arrow redraws. Stretch-copies the 640 by 70 area to the window with the game palette.
**Calls:** `HMemCpy`, `1080:0d56`, `SelectPalette`, `WinGStretchBlt`, `SelectObject`.
**Yields / blocks / timing:** none
**Edge cases:** Fewer than 10 items leave the rest of the strip showing the background. Items are drawn before the frame so the frame covers their edges.
**Evidence:** `re/export/fn/1008_02a2.c`; callers `DLG_INVENTORY` (three calls).
