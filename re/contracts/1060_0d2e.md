# 1060:0d2e inferred_parse_number_list
Status: understood · Cluster: game variables · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Parse a list of whole numbers that may use repeat and ramp shorthand (confirmed).
**Inputs:** `[bp+6]` near pointer to the text, `[bp+8..a]` far pointer to the output array of 16-bit values, `[bp+c]` how many values to produce.
**Outputs / state written:** Reads numbers (optional `-`, digits) separated by spaces, commas, CR or LF. `V(n)` produces `n` copies of `V`. `V(n d)` produces `n` values starting at `V` and changing by `d` each step (`d` may be negative), e.g. `0(9 0)` nine zeros, `414(11 -4)` 414, 410, 406 ... for 11 values. Stops when `count` values are written or the text ends; the rest of the array is zero-filled. Returns the number of values written.
**Calls:** stack probe.
**Yields / blocks / timing:** none
**Edge cases:** A repeat count of 0 or less writes nothing. A malformed bracket (no closing parenthesis) writes nothing for that item. Values wrap at 16 bits.
**Evidence:** `re/export/fn/1060_0d2e.c`; the forms occur in `PosX=`, `PosY=` and `ScaleVal=` lines of the data (for example `PosY=0(9 0) 420(28 -2) 364(24 -1)` and `ScaleVal=128(4) 110(4) 96(4) 96`).
