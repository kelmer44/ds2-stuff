# 1088:06b4 inferred_load_file
Status: understood · Cluster: resource layer · Convention: cdecl far (glue table far pointer, name near pointer)

**Purpose (confirmed):** Return a pointer to the bytes of a named resource: an alias into the in-memory glue copy when there is one, otherwise a fresh buffer read from the glue file (confirmed).
**Inputs:** `[bp+6..8]` far pointer to the glue table (`DS:275e`), `[bp+a]` near pointer to the resource name.
**Outputs / state written:** Returns the far pointer in DX:AX, or 0. The name is copied to `DS:3662` and normalised; the entry is found with `inferred_find_entry` and copied (22 bytes) to the stack. The path is built at `DS:3670` as `directory[dirId] + glueName`. If the glue file has an in-memory copy (slot at table offset `0x130a`), the result is `inferred_make_alias_selector(base + offset, size)` : 0. Otherwise: `OpenFile`, `_llseek` to the entry offset (error "Couldn't seek to position" if the result differs), `mem_alloc(size)` (error "can't load game files (no memory)" if null), `inferred_read_file_to`, close.
**Calls:** `1088:04c8`, `1088:051c`, `1088:062c`, `1088:0000`, `1090:0000`, `1098:0000`, `1098:0248`, `OpenFile`, `_llseek`, `_lclose`, `HMemCpy`, `lstrcmpi`, `OutputDebugString`.
**Yields / blocks / timing:** none
**Edge cases:** Not found: if the name's characters from index 7 equal the string at `DS:2315` the function returns 0 silently, otherwise it shows "load_file: Unable to find file" and returns 0. The directory is chosen by the per-glue byte at table offset `0x128a + glueIndex`. A file read this way must be raw; a compressed file only works through its in-memory copy. The caller owns the result and frees it with `inferred_mem_free`.
