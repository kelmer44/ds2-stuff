Status: understood · Cluster: dialogs · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Read a save file and put the game back into that state.
**Inputs:** The owner window and the slot number (0 to 9).
**Outputs / state written:** Opens `DS2SGnn.SAV`, reads it whole, unscrambles it (`1018:05c0`), switches the game off (`DS:0044` = 0), unloads the room (`1048:21b0`, `1050:035a`) and takes the words described under `1018:09ce`: mode, position (also into the walk target `DS:0086`/`0088`, `DS:9b98`/`9b9a`), facing, cursor mode, speed.
