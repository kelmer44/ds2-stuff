# 1080:09f8 inferred_create_bitmap_from_image
Status: understood · Cluster: graphics and palette · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Make a Windows bitmap from a loaded picture and remember its size.
**Inputs:** A device context and a near pointer to the image record.
**Outputs / state written:** If the record has no file data it reports an error ("np_process_image", "NULL pointer assignment") and returns 0. Otherwise copies four header words of the picture (+0x12, +0x16, +0x26, +0x28) into the record (+8 to +0xe), zeroes the last two in the header, creates the bitmap with `CreateDIBitmap` (with initial data from the picture's pixel offset) and stores it at +0. Reports "Unable to create bitmap" if that fails. Returns 1.
**Calls:** `CreateDIBitmap`, `1098:0000` (error report).
**Yields / blocks / timing:** none
**Edge cases:** Returns 1 even when the bitmap could not be created (only the message shows).
