# 1098:0326 inferred_load_file_or_plain
Status: understood · Cluster: resource layer · Convention: cdecl far (table far pointer, name near pointer)

**Purpose (confirmed):** Load a named file as a whole buffer: from a plain file on disk while the index is not loaded yet, otherwise through the index (confirmed).
**Inputs:** `[bp+6]` near pointer to the glue table (`DS:275e`), `[bp+8..a]` far pointer to the name.
**Outputs / state written:** If the table's 'loaded' word (offset 4) is 0: opens the file by name, finds its length with `_llseek`, allocates that much, reads it with `_hread` and returns the buffer (errors: file missing shows the report box and returns 0; allocation failure shows a box, sets `DS:0048` = 1 and calls `1010:0230`; read failure frees the buffer, shows a box and does the same). Otherwise returns `inferred_load_file(table, name)`.
**Calls:** `1088:06b4`, `1090:0000`, `1090:0068`, `1098:0000`, `1098:0248`, `1010:0230` (fatal exit path, unread), `OpenFile`, `_llseek`, `_hread`, `_lclose`.
**Yields / blocks / timing:** none
**Edge cases:** Used for `fix.pal` and for `OBJ_nnnn.dat`, the first things loaded after the index. In normal play the second branch runs. The error path sets a global exit flag at `DS:0048` instead of returning an error code.
**Evidence:** `re/export/fn/1098_0326.c` and `.asm`; callers `1028:03d0` (fix.pal) and `1048:093e` (OBJ file).
