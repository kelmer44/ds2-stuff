# 10c0:0000 inferred_stretch_dib
Status: understood · Cluster: startup helpers · Convention: cdecl far, caller cleans

**Purpose (confirmed in outline):** Stretch a rectangle of one 8/16/24/32-bit picture into a rectangle of another of the same depth, clipping both to the pictures.
**Inputs:** A flags word, the source rectangle (x, y, width, height), the destination rectangle, and the source and destination picture headers and pixel pointers (the names in the checks are `pdibDst`, `lpDst`, `pdibSrc`, `lpSrc`, `DstX/Y/XE/YE`, `SrcX/Y/XE/YE`).
**Outputs / state written:** Checks its arguments with asserts from the source file `stretch.c` (null pointers, negative sizes, equal bit depth), then clips the destination rectangle to the destination picture's width and height. When the destination rectangle is cut at the left, top, right or bottom, the source rectangle is cut by the same fraction using the 16.16 helpers `10c8:059a` and `10c8:054e`. Then calls `10c8:0040` to copy. Returns 1.
**Calls:** `10d0:039c` (assert), `10c8:059a`, `10c8:054e`, `10c8:0040`.
**Yields / blocks / timing:** none
**Edge cases:** Rectangles entirely outside the destination are skipped (nothing is drawn). The assert helper is the C runtime's, replaced in a port by ordinary checks.
**Evidence:** `re/export/fn/10c0_0000.c`; caller `1020:0a06`, the scaled-image routine `1020:0656`.
