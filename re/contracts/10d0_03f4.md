**Purpose (confirmed):** C runtime wrapper for DOS 'find first file' (INT 21h function 4Eh, through `DOS3Call` when running under Windows) (confirmed).
**Inputs:** Far pointers and attribute word as pushed by the caller (`1028:09f6` passes a copy of a glue name, attribute 1 and a 44-byte buffer).
**Outputs / state written:** Saves and restores the DOS disk transfer area around the call (functions 2Fh and 1Ah). Returns 0 when a file matched and a non-zero DOS error otherwise. Nothing else is changed.

**Edge cases:** A relative name is searched in the current DOS directory only, so the result depends on where Windows started the program.
