# 1000:0000 inferred_set_rect
Status: understood · Cluster: main window and input · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Fill a four-word rectangle in a fixed global and return a pointer to it, like the Windows `SetRect` call without a destination argument.
**Inputs:** Four words (left, top, right, bottom), pushed so that the first parameter is the one nearest the return address.
**Outputs / state written:** Writes the four words to `DS:2d4a`, `2d4c`, `2d4e`, `2d50` and returns the near pointer `DS:2d4a` (AX = offset, DX = DS).
**Calls:** only the stack-check helper `10d0:029e`.
**Yields / blocks / timing:** none
**Edge cases:** The rectangle is shared: a second call overwrites the first, so callers use the result at once. In the game window procedure it is called with (0, 0, 640, 40) after the pop-up strip closes and with (0, 380, 640, 480) elsewhere, and the result goes to the window's invalidate call.
**Evidence:** `re/export/fn/1000_0000.asm`; the two calls in `WINPROC` (`1000:0801`, `1000:090e`) and the pushes before them; two more calls in `1078:0000`.
