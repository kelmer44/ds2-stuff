# 1048:24ee inferred_start_room_media
Status: understood · Cluster: script and rooms · Convention: cdecl far, caller cleans

**Purpose (confirmed in outline):** Run the room's entry section: pick the first matching entry, play its video, put the player at its starting position and apply its variable changes.
**Inputs:** A device context and the room record (far).
**Outputs / state written:** Walks the entry list (+2, next at +0x91). A record matches when its `From=` room (+0xe) is 0 or equals the variable `FromRoom` and its conditions are true (`1060:07f6`). For the first match: if the record asks for a palette change (+0x14 bit 0) and the current palette differs from the saved one it fades to black (`1080:02f0`) and blanks the screen, and the palette is made again (`1080:049a`). **Video:** a name at +0x1a starting with `T` is a transition video, played full screen (0, 0, 320, 240); names starting `cut` or `abh` are cut-scenes; the options skip them (`DS:0050` clears the name for transitions, `DS:0052` for cut-scenes) and room 0x5dd with `DS:005a` set also skips. Otherwise it hides the cursor and sends the MCI commands `open <dir><name>.avi alias vfw`, `window vfw handle %d`, a palette command when the record asked for it, `put vfw destination at x y w h` (or `fullscreen` / `window` depending on the video-size option `DS:0066`), clears the screen unless the option is the 0x2e6 mode, and `play vfw from 0 wait`, then stops and closes it, re-enables the mixer and restores the cursor. If there is no video it resets the system palette (`1028:014e`). **Player:** sets the player's position (`DS:3cae`, `DS:3cb0`) from +4, +6, the facing from +0xc (below 8, else 0), clears the path (`DS:097c` = -1), sets the walk target and, if the position is blocked, finds the way out with `1010:07c6`. Applies the record's change lists (`1060:092e`, `1060:0a0a` three times). If the record asked for a second palette action (+0x14 bit 1) it fades and rebuilds the palette again.
**Calls:** `1060:07f6`, `1060:0b00`, `1060:092e`, `1060:0a0a`, `1080:02f0`, `1080:049a`, `1028:014e`, `1028:0b48`, `1010:07c6`, `10a8:0000`, `10d0:0604` (compare), `mciSendString`, `GetSystemPaletteEntries`, `PatBlt`.
**Yields / blocks / timing:** none
**Edge cases:** If no entry matches nothing happens. Videos are skipped by blanking their name, so the rest runs as usual.
