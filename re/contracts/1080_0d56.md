# 1080:0d56 inferred_draw_image_record
Status: understood · Cluster: graphics and palette · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Draw an image record (picture or sprite) into a destination bitmap at a position, with optional transparency (confirmed).
**Inputs:** `[bp+6..8]` destination bitmap header far pointer, `[bp+a]` and `[bp+c]` destination pixels far pointer, `[bp+e]` x, `[bp+10]` y, `[bp+12..14]` image record far pointer, `[bp+16]` source x, `[bp+18]` source y, `[bp+1a]` keyed flag.
**Outputs / state written:** Reads the record's file data (at +2/+4), takes pixels at `bfOffBits` and the header at +0xe, forces y and source y up to 0 when negative (x and source x are not clamped), uses the picture's full width and height as the rectangle, key colour 0, and calls `inferred_draw_bitmap_clipped`. Returns 1.
**Calls:** `10b0:0000`.
**Yields / blocks / timing:** none
**Edge cases:** Negative y and source y are set to 0 here, not clipped; negative x is passed on and clipped later. Used by the dialog and inventory code (segment `1008`, `1068`) and by the compositor.
