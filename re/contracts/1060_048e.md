# 1060:048e inferred_register_local_var
Status: understood · Cluster: game variables · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Give a room-local variable name a slot in the variable list (confirmed).
**Inputs:** `[bp+6]` near pointer to the variable name, e.g. `101OpenDoor`.
**Outputs / state written:** Searches the sorted name table like `inferred_find_var` (without the digit shortcut). If the name is already there it returns its index. Otherwise it copies the name into the slot where the search ended (the first slot that sorts after it), sets that variable's value to 0 and returns the index. Slots 1 to 20 hold placeholder names `AAAAAAAAAAA01` to `AAAAAAAAAAA20` that room local names overwrite in order.
**Calls:** `lstrcmpi`, `lstrcpy`.
**Yields / blocks / timing:** none
**Edge cases:** This keeps the list sorted only because the room files list their `LocalVar=` names in ascending order (true for all 83 shipped rooms, at most 20 per room, all starting with the room number digits). More than 20 names, or an unsorted list, would overwrite a real variable or break the binary search. The slots are reset when the room is unloaded (`1048:21b0`).
**Evidence:** `re/export/fn/1060_048e.c`; `re/export/fn/1048_21b0.c` (placeholder reset loop); all 83 room files checked: at most 20 names, sorted, digit first.
