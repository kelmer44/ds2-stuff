# 10c8:0073 inferred_scale_ratio_class
Status: understood · Cluster: 32-bit bitmap helpers · Convention: register call: eax = source size, edx = destination size; ends with `ret`

**Purpose (confirmed):** Classify the ratio between a source size and a destination size and return the ratio as a fixed-point number plus a jump-table index.
**Inputs:** `eax` and `edx`: the two sizes.
**Outputs / state written:** Returns in `eax` a table index and in `edx:ebx` the ratio source/destination as an integer part and a 32-bit fraction. Equal sizes: edx 1, ebx 0, index 0x18. Source smaller: exactly 1/2 gives index 4 (ebx 0x80000000), exactly 1/4 index 8 (ebx 0x40000000), otherwise index 0xc with the fraction `(source << 32) / destination`. Source larger: exactly 2 gives index 0x10 (edx 2), exactly 4 index 0x14 (edx 4), otherwise index 0x18 with edx the integer part and ebx the fraction.

**Edge cases:** The index is used as an offset into the dword table at `10c8:0000`.
