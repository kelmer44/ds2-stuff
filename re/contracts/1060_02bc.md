# 1060:02bc inferred_find_var
Status: understood · Cluster: game variables · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Return the index of a game variable by name, or 0 when it does not exist (confirmed).
**Inputs:** `[bp+6]` near pointer to a NUL-terminated name (the pointer's segment is the data segment).
**Outputs / state written:** Binary search over the sorted name table (`DS:05f0`, 25-byte slots, `DS:5cda` entries) with a case-insensitive compare. If the name's first character is below `:` (digits, `!`, and similar) the search range is limited to slots 0 to 0x15; otherwise it is slots 0 to count - 1. Returns the matching slot or 0.
**Calls:** `10d8:0000` (case-insensitive string compare), stack probe.
**Yields / blocks / timing:** none
**Edge cases:** Index 0 is the dummy variable `!Dummy`, so an unknown name reads and writes the dummy variable. The search ends when the two bounds are one apart, then the two remaining slots are compared once each. The name table must be sorted case-insensitively, which `inferred_load_game_vars` checks.
