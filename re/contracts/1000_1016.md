# 1000:1016 POPUPPROC
Status: understood · Cluster: main window and input · Convention: Pascal far (dialog procedure: window, message, wParam, lParam)

**Purpose (confirmed in outline):** The dialog procedure of the dialog template `ds2POPUP`, the strip of buttons across the top of the screen. It closes the dialog with the number of the button pressed and lets the keyboard move the mouse pointer.
**Inputs:** The standard dialog arguments; `param_4` is the message, `param_3` wParam, `param_5` the dialog window.
**Outputs / state written:**
- `WM_INITDIALOG` (0x110): moves the dialog to the top-left corner, 640 by 40 pixels, shown without changing the stacking order; stores the window in `DS:9e24`. If a key was held back in `DS:8f9a` it posts a menu-key system command and that key down to the dialog and clears it. Sets the focus to nothing and calls `SystemParametersInfo(2, 0, ...)` (switches the warning beep off). Returns 0.
- `WM_COMMAND` (0x111): stores the control number in `DS:0c1e`. Controls 100, 101, 102, 104, 105, 300 and 301 end the dialog with that number as result; control 2 (cancel) ends it with 0; anything else is ignored.
- `WM_USER` (0x400): ends the dialog with 0.
- `WM_SYSCOMMAND` (0x112): the size, move, minimise, maximise, close-type commands are swallowed (return 1); others return 0.
- `WM_SYSKEYDOWN` (0x104): the cursor keys, the number-pad keys 8, 2, 4, 6 and the letters I, K, J, L move the mouse pointer up, down, left, right by the step in `DS:006c` through `SetCursorPos`, keeping the position in `DS:3c54` (x, 0 to 640) and `DS:3eb0` (y, 0 to 480); every move raises the step by 2 up to 10. The letters F, H and O are forwarded to the dialog as a menu key plus key press. Returns 1.
- `WM_SYSKEYUP` (0x105): clears `DS:2d5a`. `WM_WINDOWPOSCHANGING/CHANGED` (0x46, 0x47) return 1, `WM_GETDLGCODE` (0x87) returns 0xffff (the dialog wants every key).
**Calls:** `SetWindowPos`, `PostMessage`, `SetFocus`, `SystemParametersInfo`, `EndDialog`, `SetCursorPos`, stack-check helper `10d0:029e`.
**Yields / blocks / timing:** none (runs inside the modal dialog loop that `WINPROC` starts).
**Edge cases:** The step is only raised here, it is reset to 2 by `WINPROC` (`1000:0956`) and by the inventory dialog. The button numbers are the command numbers `WINPROC` handles (100, 101, 102, 104, 105 open the dialogs in segments `1010` and `1018`, 300 the help file, 301 the about box).
**Evidence:** `re/export/fn/1000_1016.c` and `.asm`; the opening code in `WINPROC` (`1000:07af..0831`) creates the dialog from the template name at `DS:0b38` ("ds2POPUP") and runs it when the pointer is at the top edge, no video or cut-scene runs, and the checked game variables say so.
