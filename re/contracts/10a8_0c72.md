# 10a8:0c72 inferred_speech_deadline
Status: understood · Cluster: audio and video (MCI, WaveMix) · Convention: cdecl far, caller cleans

**Purpose (inferred):** Work out how long a subtitle stays up from the size of its sound.
**Inputs:** A 32-bit base time (two words) and a near pointer to a 32-bit sound size.
**Outputs / state written:** Multiplies the size by the timer mode `DS:6114` and divides by 22, adds the result to the base into the value at the pointer, then adds a reading-time bonus to the returned low word by the options: +250 for dialog option 0x3d5; otherwise +1000, +4500, +10000 or about -31000 for the read-speed choices 0x2be, 0x2bf, 0x2c0, 0x2c1; the base's low word is added to the return.
**Calls:** `10d0:052a` (32-bit multiply), `10d0:0490` (32-bit divide).
**Yields / blocks / timing:** none
**Edge cases:** The size is overwritten with the sum. The meaning of the units (ticks versus milliseconds) is not confirmed.
