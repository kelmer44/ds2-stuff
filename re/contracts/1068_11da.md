# 1068:11da inferred_entry_selected
Status: understood · Cluster: conversations · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Carry out the choice of one conversation entry and return the next node (confirmed). This is the original's `EntrySelected`.
**Inputs:** Dialog handle and the index of the chosen item in the list box (the entry pointer is the item's data).
**Outputs / state written:** In this order: (1) if the entry is not `persist` (flag bit 1 clear) its flags are set to 0, so it is no longer listed unless unhidden; (2) the **assign list** (+0x25): for each record whose condition is true, the variable named in the record is set to the value of its expression; (3) the **hide list** (+0x19): each target entry's flags are set to 0; (4) the **unhide list** (+0x1d): each target entry gets bit 0 set; (5) the **destroy list** (+0x21): each target entry gets bit 2 set, which keeps it out of every later list (`flags & 5 == 1` fails); (6) the player's line: the text record of the entry is shown as a subtitle "Mike :" + text with its sound (`10a8:0638`); (7) the reply messages (chain at +0x11/+0x13): for each, the speaker number selects a name from the speaker table (5 slots of 0x14 bytes, default `AUNQUE` when unnamed), the variable `SysTalking<n>` is looked up, and the subtitle `Name :` + text is shown with the speech sound; (8) the **goto list** (+0x15): the first record whose condition is true gives the next node (its resolved pointer, +0x2a/+0x2c), or 0 when none is true or the target name did not resolve.
**Calls:** `1068:0edc`, `1060:02bc`, `10a8:0638`, `lstrcpy`, `lstrcat`, `_wsprintf`, `GetDlgItem`, `SendMessage` (item data).
**Yields / blocks / timing:** none
**Edge cases:** Every condition is `inferred_eval_rpn`; a record without a parenthesised condition is always true. A goto target that is not the name of a node (such as `exit,Greeting`) resolves to 0, which ends the conversation.
