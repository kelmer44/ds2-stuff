# 1000:0236 WINPROC
Status: understood · Cluster: main window and input · Convention: Pascal far (window procedure)

**Purpose (confirmed in outline):** The main window's message handler: the game's timer, mouse, keyboard, menu-command and shutdown logic all start here.
**Inputs:** The standard window arguments (window, message, wParam, lParam; the mouse position is also read from `DS:3c54`/`3eb0`).
**Outputs / state written:**
- **WM_TIMER (0x113):** repaints if something is invalid, reads the pointer, closes the pop-up strip (`DS:003e`, window `DS:9e24`) when the pointer is below y = 280 and the inventory bar (`DS:0040`, window `DS:3eb2`) when it is above y = 380, by posting private message 0x400 to them. Compares the multimedia clock with the next due time `DS:0ad6` and, when due, sets the next one `1000 / DS:0046` ms later and runs the game tick `1038:086e`.
- **WM_MOUSEMOVE / WM_NCHITTEST (0x200, 0x84):** in normal play it reads the pointer, builds the three cursors (`DS:978e`..`9792`) from the flags `1050:0062` returns, and opens one of two modal dialogs: the **pop-up strip** (pointer at the top edge, see `POPUPPROC`) or the **inventory bar** (template `DS2INVENTORY`, pointer below y = 470, see `DLG_INVENTORY`) when no video, cut-scene or pending action runs and `LastAction` is 4. Afterwards it repaints the strip it covered (`1000:0000`) and, for the pop-up, posts the chosen button as a command and puts the pointer at (320, 200). In menu mode (`DS:007c` = 2) it only picks the cursor from the menu rectangles.
- **Left button down (0x201):** refreshes the `DS:006e` flag from a variable. **Left button up (0x202):** while a video waits (`DS:0368`) it sends `stop vfw wait`; in menu mode (`DS:007c` = 2) a click inside x 149 to 490 and one of four bands (y 198 to 250, 256 to 310, 314 to 368, 372 to 426) calls the dialogs `1010:011e`, `1018:01fa`, `1010:0336`, `1010:0230`; in play it ends a cut-scene wait (`DS:008a`, repainting the screen) or runs the click handler for the cursor mode `DS:770e`: 0 `1058:0b08`, 1 `1058:0ae2` (then posts a mouse move), 2 `1058:0abc`. **Right button down (0x204)** steps the cursor mode through 0, 1, 2 when idle; **right button up (0x205)** ends a cut-scene wait.
- **WM_COMMAND (0x111):** control 100 `1010:011e`, 101 `1018:01fa`, 102 `1018:0566`, 104 `1010:0230`, 105 `1010:0336`, 300 opens the help file (`dsii.hlp`), 301 opens the about box. These are the numbers the pop-up strip returns.
- **Keys:** key down (0x100) goes to `1000:12be` (or, while a video plays, becomes a left click); key up (0x101) resets the pointer step to 2; system key down (0x104) for A, O or Y moves the pointer to (0, 0) and remembers the key in `DS:8f9a` so the pop-up strip can replay it.
- **Window housekeeping:** WM_PAINT (0xf) repaints the picture and blacks out the area outside the 640 by 480 game area; WM_ACTIVATE (6) and WM_MOUSEACTIVATE-like (0x21) keep the window on top and focused; WM_QUERYNEWPALETTE (0x30f) realises the palette (`1080:0920`); private messages 0x3bd (sound notification, `10a8:057a`), 0x400 (continue a walk-then-act, clears `DS:036c`, runs `1058:01e0`) and 0x120 (shows a message box with the text, `1098:0248`). System commands (move, size, minimise) are swallowed.
- **WM_CLOSE (0x10):** `1010:0ae0`, blacks out the screen, destroys the window. **WM_DESTROY (2):** frees the sound and picture buffers, the cursors and the memory device context, unloads the room (`1048:21b0`), frees the item and conversation data and posts the quit message.
**Calls:** many; `1000:12be`, `1000:0000`, `1038:086e`, `1038:01e4`, `1058:0abc`, `1058:0ae2`, `1058:0b08`, `1058:01e0`, `1060:0b00`, `1060:0b26`, `1078:1238`, `1010:*`, `1018:*`, `1028:*`, `1080:*`, `1088:*`, `10a8:*` and the Windows window, GDI, MCI and timer calls.
**Yields / blocks / timing:** The pop-up and inventory dialogs are modal, so this function does not return while one is open (the timer keeps arriving through the dialog's idle messages). The game tick rate is set by `DS:0046` (5, 15 or 24).
**Edge cases:** All mouse and key input is ignored while `DS:036e` is 1 (a dialog or pause is up). In the top-level `0x201` and `0x204` paths `DS:036e` is restored from its value at entry. The timer test uses `timeGetTime`, so the game tick can fire less often than the rate when the machine is slow (no catch-up).
