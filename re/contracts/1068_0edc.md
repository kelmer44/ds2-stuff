# 1068:0edc inferred_eval_rpn
Status: understood · Cluster: conversations · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Evaluate a compiled condition expression (postfix) used by `goto = (expression) Node` (confirmed).
**Inputs:** `[bp+6..8]` far pointer to the array of 16-bit expression cells, `[bp+a..c]` far pointer to the current length (the index of the cell to read next, counted down).
**Outputs / state written:** Reads the cell at index `length - 1` and decrements the length (error box "Internal error: compute list" when it is 0). A cell with bit 15 clear is an operand: with bit 14 set it is a game variable (the cell without bit 14 is the variable index and the value is read from the variable table `DS:5e14`), otherwise a literal number. A cell with bit 15 set is an operator on the next two evaluated values (right operand evaluated first): `+` add, `-` left minus right, `*` multiply, `/` integer division left by right (error "Internal error: divide by zero" returns 0), `&` and, `|` (0x7c) or, `^` xor, `<` 1 if left < right else 0, `>` 1 if left > right else 0, `=` 1 if equal else 0. The result is also written as a trace text `"%d %s = %d"` into the buffer at `DS:90b4`.
**Calls:** `1098:0248` (error box), `_wsprintf`, recursion for both operands.
**Yields / blocks / timing:** none
**Edge cases:** Values are signed 16-bit. There is no `!` or `<=`: conditions use the three comparisons and `&`/`|`.
