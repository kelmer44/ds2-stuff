# 10a8:07dc inferred_pump_speech_queue
Status: understood · Cluster: audio and video (MCI, WaveMix) · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Start the next queued speech line if nothing is playing and no wait is pending.
**Inputs:** none
**Outputs / state written:** Does nothing while a cut-scene wait (`DS:008a`) is on. If the queue is not empty: marks busy, copies the subtitle text to `DS:262a`-area buffer (`10a8:0d1a`), plays the sound on channel 3 (`10a8:015e`), clears `DS:2776`, calls `1058:0000`, frees the text copy, sets the subtitle position (`DS:27a0`, `27a2`), computes the deadline (`DS:279c`) from the sound's size (`10a8:0c72`), sets the previous line's variable to 0 and the new one's to 1, and moves the head `DS:276e`. If the queue is empty and the last line has finished it posts message 0x400 with 0x1ada to the window `DS:8e3a` when a continuation waits (`DS:2774`) and sets the line's variable to 0.
**Calls:** `10a8:0d1a`, `10a8:015e`, `10a8:0c72`, `1058:0000`, `1090:0068`, `GetTickCount`, `PostMessage`.
**Yields / blocks / timing:** none
**Edge cases:** The variables set to 1 and 2 are the game variables with the `SysTalking%d`-style indexes; 999 means none.
