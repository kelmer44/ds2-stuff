# 1060:0652 inferred_parse_terms
Status: understood · Cluster: game variables · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Turn the text of a condition or assignment line into the 16-bit term words (confirmed).
**Inputs:** `[bp+6]` near pointer to the text, `[bp+8..a]` far pointer to the output word array.
**Outputs / state written:** Reads up to 10 tokens separated by spaces or commas. A token may start with a prefix: none (plain `NAME`) = test `== 1` or set 1; `!` = op 1 (`== 0` / set 0); `*` = op 2; `+` = op 3; `-` = op 4; `^` = op 5; `@` = op 6; `/` = op 7. The word is `index | (op << 12)`. A token `=NAME,value` becomes `0x8000 | ((value & 31) << 10) | index`. Returns the number of terms written.
**Calls:** `1060:0222` (token), `1060:02bc` (index), `1060:0c44` (number).
**Yields / blocks / timing:** none
**Edge cases:** A value above 31 is cut to 5 bits. An unknown name becomes index 0 (the dummy). Parsing stops at the first empty token.
