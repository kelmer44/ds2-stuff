# 10a8:0a1e inferred_play_music
Status: understood · Cluster: audio and video (MCI, WaveMix) · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Start the MIDI file for a music name, unless it is already the current one.
**Inputs:** A far pointer to the music name (up to 11 characters).
**Outputs / state written:** Returns 0 if the name equals the current one (`DS:262a`). Otherwise stores it, runs `10a8:0000`, stops and closes the old `midifile`, then sends `open sequencer!<music folder><name>gm.mid alias midifile` (`gm` when `MidiType` is 0x14a, else `fm`). If music is on it sets the sequencer volume to `DS:006a` and sends `play midifile from 0`. Runs `10a8:0000` again and returns 1.
**Calls:** `mciSendString`, `MCIGetDeviceID`, `midiOutSetVolume`, `10a8:0000`.
**Yields / blocks / timing:** none
**Edge cases:** The file name is the music name plus `gm` or `fm`; the music folder is `sndtrack\`.
