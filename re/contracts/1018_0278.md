# 1018:0278 SAVEGAMEPROC
Status: understood · Cluster: dialogs · Convention: Pascal far (dialog procedure)

**Purpose (confirmed):** Dialog procedure of the save-game window: ten slots whose titles can be edited, one chosen with a radio button.
**Inputs:** The standard dialog arguments.
**Outputs / state written:** Initialise as the load dialog does (titles at `DS:2d82`, 50 bytes per slot, used flags at `DS:2f76`) and gives the focus to OK. Clicking a title control ticks its radio button; ticking a radio button focuses and selects the text of its title control. OK (1): takes the ticked slot; if it is already used it asks "¿Desea sobreescribir una partida anterior?" (title "Sobreescribiendo Partida") and returns to the dialog on no. Otherwise the typed title (up to 32 characters) is stored in the settings file (`SAVEGAME`, `Title%02d`), the flag `Saved%02d` is set to 1 and the game is written with `1018:09ce`; the dialog closes with 601 + slot. Cancel (2) closes with 1.
**Calls:** `1018:09ce`, `1030:003e` (write string), `1030:0000` (write int), `1030:006a`, `1030:0094`, `GetWindowText`, `MessageBox`.
**Yields / blocks / timing:** Modal.
**Edge cases:** Empty titles are accepted as typed.
