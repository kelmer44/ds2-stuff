# 1000:1a98 inferred_next_word
Status: understood · Cluster: main window and input · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Find the next blank-separated word in a string: skip spaces and tabs, then report where the word starts and how long it is.
**Inputs:** A far pointer to the text (offset, segment), and a far pointer to an int that receives the length.
**Outputs / state written:** Writes the word length to `*length` (0 when there is none). Returns a pointer to the first character of the word, or 0 when only blanks or the end of the string remain. The text is not modified.
**Calls:** only the stack-check helper `10d0:029e`.
**Yields / blocks / timing:** none
**Edge cases:** Only space and tab separate words. The length counts up to the next space, tab or end of string. The returned offset is a near pointer: the segment is not part of the result.
