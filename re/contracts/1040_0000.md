# 1040:0000 inferred_walk_line_clear
Status: understood · Cluster: walking · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Test whether a straight line between two grid cells crosses only walkable cells (confirmed).
**Inputs:** Four cell coordinates after a first word: x1, y1, x2, y2 (columns and rows of the 80 by 48 grid).
**Outputs / state written:** Returns 1 if every cell on the Bresenham line is walkable and 0 as soon as one is not. A cell is not walkable when the working grid at `DS:3eba` (16-bit words, row stride `DS:16e4`) holds -1; walkable cells hold -2. The line steps along the longer axis, with the usual error term.
**Calls:** none.
**Yields / blocks / timing:** none
**Edge cases:** The end cell itself is not tested (the loop stops when the end coordinate is reached). The working grid must have been filled by `1040:011a` first.
