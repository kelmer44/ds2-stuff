# 10a0:0000 inferred_sin
Status: understood · Cluster: math · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Sine of an angle in a 1024-unit circle, result scaled so 16384 is 1.0 (confirmed).
**Inputs:** `[bp+6]` angle: bits 0-7 index inside a quadrant, bits 8-9 the quadrant.
**Outputs / state written:** Returns the 16-bit signed sine. Quadrant 0 reads the table forwards, 1 reads it backwards from `DS:266a`, 2 is the negated table forwards, 3 the negated backwards.
**Calls:** stack probe.
**Yields / blocks / timing:** none
**Edge cases:** Higher angle bits are ignored. The table at `DS:246a` holds 257 words = round(16384 * sin(i * (pi/2) / 256)) for i = 0..256 (checked: 0, 101, 201, ..., 11585 at i = 128, 16384 at 256).
