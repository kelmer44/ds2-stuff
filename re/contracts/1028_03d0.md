# 1028:03d0 inferred_init_game_session
Status: understood · Cluster: resource layer · Convention: cdecl far, caller cleans

**Purpose (confirmed in outline):** Set up everything the game needs after the window exists, then start the first room and the timer.
**Inputs:** The main window.
**Outputs / state written:** Builds two 256-byte tables: the upper-case map (`DS:92b4`) and a character-class table (`DS:5d0e`: 1 lower case, 2 upper case or underscore, 4 digit or `!`, 8 the operators `+ - * / = & | ( )`, 0x10 space, comma, tab and zero) used by the script readers. Takes over the palette (`1028:0000(1)`), shows the wait cursor, starts the sound `MM001` (`10a8:0a1e`), resets the system palette (`1028:014e`) and blanks the screen. Allocates a 0x7740-byte work block (`DS:0010`). Loads `GL00_WLK.000` and `GL00_TXT.000` whole, reads `GameVar.IDX`, sets the variable `TRUE` to 1, parses `OBJ_9999.dat` (`DS:8728`) and reads `fix.pal` into the fixed-palette store. Builds the player's eight sprite sets of nine pictures each (216 bytes per set): sets 0 and 4 to 7 are loaded as pictures, sets 1 to 3 are copies of sets 7, 6 and 5. Clears the 50 saved per-room blocks, sets `FromRoom` to -1 and starts the first room (`1048:3236`). Prepares the file dialog (`1010:0000`). Loads the cursors: arrow, `cHand`, `cUseIt`, `cLook`, `cLookAt`, `c4Ways` and puts the cursor table in verb mode 1. Sets a system option (`SystemParametersInfo` 0x17). On Windows 3.x (version below 95) speeds the system timer (`1028:0964`), sets `DS:6114` to 2 and starts a window timer of 1 ms; on Windows 95 it starts a 83 ms timer (about 12 a second) and sets `DS:6114` to 1. If no timer is free it shows "Too many timers" with retry and cancel.
**Calls:** `1028:0000`, `1028:00b6`, `1028:014e`, `1028:0964`, `1010:0000`, `1048:093e`, `1048:3236`, `1060:0b26`, `1060:10ba`, `1080:0890`, `1088:003e`, `1090:0000`, `1098:0326`, `10a8:0a1e`, `LoadCursor`, `SetTimer`, `GetVersion`.
**Yields / blocks / timing:** none
**Edge cases:** The timer message handler `WINPROC` compares the multimedia clock, so the two timer modes give the same game speed. Returns the timer id, or 0 when the player cancels.
