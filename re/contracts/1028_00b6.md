# 1028:00b6 inferred_fixed_palette_store
Status: understood · Cluster: resource layer · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Keep the fixed part of the game palette (`fix.pal`) and impose it on a room's palette.
**Inputs:** A far pointer to a 256-entry colour table (4 bytes per entry) and a mode word.
**Outputs / state written:** Mode 0: the first time, copies the 256 entries to `DS:2fe6` and sets the saved flag `DS:1394` (later calls change nothing). Other modes: copies the first 100 saved entries over the start of the given table and entries 247 and 248 of the saved copy (`DS:33c2`) over the same two entries of the table.
**Calls:** none
**Yields / blocks / timing:** none
**Edge cases:** Entries 100 to 246 and 249 to 255 keep the room's own colours. Returns 0.
