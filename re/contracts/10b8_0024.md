# 10b8:0024 inferred_blit_rows_keyed
Status: understood · Cluster: 32-bit bitmap helpers · Convention: pascal-style far, callee pops 0x1c bytes; 32-bit code

**Purpose (confirmed):** Copy 8-bit pixels row by row, skipping every source byte equal to a key colour (confirmed).
**Inputs:** Stack, from `[bp+6]`: word key colour (low byte), dword source row gap, dword destination row gap, dword row count, dword row width, source far pointer, dword destination offset, destination selector word.
**Outputs / state written:** For each row copies `width` pixels, leaving destination pixels untouched where the source pixel equals the key. Source and destination row gaps are added after each row.
**Calls:** none (same one-time DPMI stub as the other routines in the segment).
**Yields / blocks / timing:** none
**Edge cases:** Works four pixels at a time with a byte-by-byte fall-back for the last 0 to 3 pixels. Does nothing for width 0.
