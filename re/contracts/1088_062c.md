# 1088:062c inferred_make_alias_selector
Status: understood · Cluster: resource layer · Convention: cdecl far, four words

**Purpose (confirmed):** Make a new selector that points at an address inside a block already in memory, so that a resource can be used in place without copying (confirmed).
**Inputs:** `[bp+6..8]` u32 linear base address, `[bp+a..c]` u32 limit (the resource size).
**Outputs / state written:** Returns the new selector in AX (the caller uses selector:0 as a far pointer). The data selector `10e0` is used as a template: its base and limit are set, `AllocSelector(10e0)` clones them, then they are restored. On failure it reports `FirstSelector!=NULL` from `gluefile.c` line 0x176.
**Calls:** `GetSelectorLimit`, `GetSelectorBase`, `SetSelectorBase`, `SetSelectorLimit`, `AllocSelector`, error reporter `10d0:039c`.
**Yields / blocks / timing:** none
**Edge cases:** The temporary change to the data selector `10e0` is not thread-safe, which does not matter in Windows 3.1. A pointer from this function is freed with `inferred_mem_free`, which falls back to `FreeSelector` because `GlobalHandle` finds no handle.
