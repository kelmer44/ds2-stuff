# 1038:086e inferred_game_tick
Status: understood · Cluster: graphics and bitmaps · Convention: cdecl far, caller cleans

**Purpose (confirmed in outline):** The timer handler: runs once per game step and moves the whole game forward.
**Inputs:** The timer message (window, message data); only the game's own timer (id 0x1234) is handled, other timers return 1.
**Outputs / state written:** 1. If a room has just been entered (`DS:610e`) and either `SkipTrans` is set or a variable says so, runs `1038:1ade` and the entry section runner (`1048:2a50`). 2. Runs the palette cycling (`1080:01de`), the speech queue (`10a8:0042`, or `10a8:0092` when a script waits for speech) and the music loop (`10a8:0bbe`). 3. While a cut-scene wait counter (`DS:008a`) runs it counts steps and, once its deadline (`DS:279c`) has passed, ends the wait: fades or repaints the screen, runs the queue and posts a mouse move. 4. In rooms above 600, when the random-sound timer (`DS:3412`) is due, it formats a random sound name `SE%03d` (three patterns depending on the room) and plays it (`10a8:06fa`), then sets the next delay to 12,000 plus a random 0 to 1,999 milliseconds. 5. While a video plays (`DS:0368`): hides the cursor and asks the media player for its mode; when it has stopped it compares the video's length and position (room 0x5dd sets `DS:005a` when they differ), stops and closes it, reactivates the sound mixer and clears the flag, then, if the player stands at its target with the two room-change variables set, changes room (`1058:0be2`), or repaints the screen. 6. Otherwise, if nothing is blocking (`DS:036e`, `DS:156c`, the cut-scene variable): sets the cursor, selects the game palette, sets `ShowMike` from 2 to 1 and a random-number variable, and runs the same sprite animation and player walking step as `1038:1ade` inline, with footstep sounds on walking frames 4 and 8 in rooms 0x25b, 0x2be, 0x2bf and 0x2c2. When the player has stopped and no video or script blocks it: if `LastAction` is not 4 it sets the cursor mode from the variable and posts a mouse move; if a click continuation is pending (`DS:008c`/`008e`, with its conditions true) it posts private message 0x400 to the window (which runs the continuation); if `GoingOut` and `SysReadyExit` are both set it changes room. 7. **Room 999 (credits):** on the first tick (`DS:1540` = -1) it blacks the screen and loads the picture (`1038:0000`); each tick it draws the visible part with `WinGStretchBlt`, moves `DS:86ba` down by 2 and `DS:1540` down by 2; when the picture is used up it frees it, sets the quit flag `DS:0048` and runs the quit routine (`1010:0230`). 8. Runs the entry section runner (`1048:2a50`) when a room has just been entered and clears the flag, clears the busy flag, and saves the clock for the random sounds.
**Calls:** `1038:1ade`, `1038:0000`, `1038:01a4`, `1038:01e4`, `1048:2a50`, `1058:0be2`, `1060:07f6`, `1060:092e`, `1060:0b00`, `1060:0b26`, `1078:0d60`, `1078:1030`, `1078:1238`, `1080:01de`, `1080:02f0`, `1080:049a`, `1020:0656`, `10a0:*`, `10a8:0000`, `10a8:0042`, `10a8:0092`, `10a8:06fa`, `10a8:0bbe`, `1010:0230`, `mciSendCommand`, `mciSendString`, `WinGStretchBlt`, Windows timer and GDI calls.
**Yields / blocks / timing:** Returns after one step. A re-entrancy flag (`DS:156c`) keeps two steps from overlapping.
**Edge cases:** The sprite loop and the walking step are a copy of `1038:1ade` that uses `1078:0d60` instead of `1078:18d8` to update the sprites. The video check uses the multimedia clock only for the random sounds; the step rate itself comes from `WINPROC`.
