# 1048:093e inferred_load_obj_file
Status: understood · Cluster: script and rooms · Convention: cdecl far, caller cleans

**Purpose (confirmed in outline):** Load and parse the object file `OBJ_nnnn.dat` into a list of room objects.
**Inputs:** The file number (a room number, or 9999 for the inventory).
**Outputs / state written:** Builds the name `OBJ_%04d.dat`, loads it as a resource and keeps it in the script buffer (`DS:3416`, size `DS:341a`), skips the first line and reads the object count with the number parser. Skips lines until the first `ObjDesc=` (0x41). For each object it allocates a 0x29-byte node, chains it in front of the list (+0xc), and reads its lines until the next `ObjDesc=`: **`ObjXY=`** (0x42) four numbers into +0..+6 (the hot-spot rectangle); **`GoStart=`** (0x20) allocates an action record at +0x18, **`LookStart=`** (0x22) at +0x10 and **`UseStart=`** (0x2c) at +0x14 and reads the section with `1048:042c`. Frees the buffer and returns the head of the list (the last object of the file comes first).
**Calls:** `1098:0326`, `1088:0892`, `1048:03c4`, `1048:0000`, `1060:0c44`, `1048:042c`, `1090:0000`, `1090:0068`, `wsprintf`.
**Yields / blocks / timing:** none
**Edge cases:** The object description name itself is not stored.
