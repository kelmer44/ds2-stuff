# 1048:042c inferred_parse_action_block
Status: understood · Cluster: script and rooms · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Read the lines of one verb section (go, look or use) of an object file, or the entry section of a room, into a chain of action records, until a given end key.
**Inputs:** The first action record (far) and the key code that ends the section (for example `GoEnd=`, `LookEnd=`, `UseEnd=`, `EntryEnd=`).
**Outputs / state written:** Reads keyed lines with the object lexer `1048:0000`. Each action record is 0x97 bytes; records form a chain through +0x93. **`Cond=`** (1): the first one fills the record given; every later one allocates a new record chained after the current one; each parses its condition terms into a new list node at +0. **`Cond2=`** (0x15) chains an alternative condition node. **`XYRoom=`** (2): five numbers into +4, +6, +8, +0xa, +0xe (the fourth and fifth are cleared when absent). **`Text=`** (3): the name goes to +0x5f, the file `NAME.txt` is loaded and its first line kept at +0x10/+0x12 (the name itself is used when the file is missing). **`Effect=`** (4) +0x52, **`Speech=`** (5) +0x5f, **`Picture=`** (6) +0x45, **`Midi=`** (0xc) +0x38, **`Dialog=`** (0xd) +0x6e, **`Cursor=`** (0x10) +0x2b (names). **`Anim=`** (7): four numbers into +0x21, +0x23, +0x25, +0x27, the video name into +0x14 and a fifth number into +0x29. **`Destroy=`** (0xe) sets +0xc to 1. **`Change=`** (8) parses assignment terms into +0x7b. **`SpeechVar=`** (0x13) is one number into +0x6c. **`WaitUntil=`** (0x19) creates a new record at +0x8f/+0x91 of the current one and makes it the current record, so the lines that follow fill the wait record. Other keys are ignored.
