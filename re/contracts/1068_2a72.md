# 1068:2a72 inferred_load_conversation_file
Status: understood · Cluster: dialogs and script · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Load a `CONVnnnn.TXT` conversation into memory and restore its saved state.
**Inputs:** A far pointer to the file name (`CONVnnnn`).
**Outputs / state written:** Builds the file name with `.TXT`, takes the number from the characters 4 to 7 (`DS:3438`), loads the file and allocates the 0x242-byte conversation record (`DS:5cba`). Reads tokens: `Conversation` (1) the name; `Declare` (2) a variable name (added to the game variables); `Node` (4) the first node (record at +0x216), whose rest is read by `1068:27a8`; `Assign` (0xb) a record at +0x212 (global assignments); `Speaker` (0xf) `1068:237a`. Then resolves the names (`1068:2144`) and handles the saved state: if no state is cached for this conversation (`DS:6116` table) it makes one from the entry flags (`1068:31a6`); otherwise the cached flags are restored (`1068:30a6`). Frees the file buffer.
