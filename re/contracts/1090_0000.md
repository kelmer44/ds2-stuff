# 1090:0000 inferred_mem_alloc
Status: understood · Cluster: resource layer · Convention: cdecl far (caller cleans), arguments = u32 size.

**Purpose (confirmed):** allocate a locked, moveable global memory block of the given size and count the allocation.
**Inputs:** `[bp+6..8]` u32 byte count.
**Outputs / state written:** returns a far pointer to the locked block (DX:AX), or 0 after reporting failure. Increments the 32-bit counter at `DS:0018`.
**Calls:** `GlobalAlloc(GMEM_MOVEABLE = 2, size)`, `GlobalLock`; on failure `1098:0248`, `1090:0068`, `10d0:01a3` (error report and exit path); `10d0:029e` stack probe.
**Yields / blocks / timing:** none.
**Edge cases:** size 0 is passed through to `GlobalAlloc`; failure never returns a block to the caller in the normal case (the exit path runs first), but the function still returns 0.
**Evidence:** `re/export/fn/1090_0000.c` and `.asm` (segment 19, 0xb4 bytes); every loader in `1028`, `1088` and `1098` allocates through it.
