Status: understood · Cluster: dialogs · Convention: Pascal far (dialog procedure)

**Purpose (confirmed):** Dialog procedure of the load-game window: ten slots, each with a title, one chosen with a radio button.
**Inputs:** The standard dialog arguments.
**Outputs / state written:** Initialise: for each of the ten slots reads the settings-file section `SAVEGAME`: key `Saved%02d` says whether the slot is used (kept in `DS:2d6e`) and `Title%02d` is its title, shown in control 501 + slot, or "--- vacio ---" if empty; the focus goes to Cancel. OK (1): finds the ticked slot; an empty one gives the message "Loading error" ("¡No puedo leer una partida vacia!") and the dialog stays open; a used one closes with 601 + slot. Cancel (2) closes with 0.
