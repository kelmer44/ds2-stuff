# 1068:006c DIALOGPROC
Status: understood · Cluster: dialogs and script · Convention: Pascal far (window or dialog procedure; the last parameter is the window)

**Purpose (confirmed in outline):** The conversation window: a 640 by 70 strip at the bottom of the screen with a list of things Mike can say, arrows to scroll it, and the replies that follow.
**Inputs:** The standard window arguments (window, message, wParam, lParam).
**Outputs / state written:** **WM_INITDIALOG (0x110):** makes the list area 480 by 50 at (80, 10) of the strip, turns the system beep off, creates the strip's bitmap, loads four pictures (frame and arrows), builds the dim table (`1008:0f86`), saves the strip background and a dimmed copy (the same method as the inventory bar), moves the dialog to y = 410 and the list box to its place, sets a variable, calls `1068:1030` to get the first node; if there is none it frees the conversation (`1068:0000`) and ends the dialog; otherwise selects the first choice and posts a key to start the keyboard handling. **WM_PAINT (0xf):** copies the saved strip, draws the arrows according to the list's top index and count, and stretches the strip to the window. **WM_MEASUREITEM (0x2c):** the height of a choice is its text measured to 464 pixels wide. **WM_DRAWITEM (0x2b):** draws the visible choices (white when selected, brown otherwise) with a small marker, works out whether there are more above or below (which arrows to show) and updates the strip. **WM_VKEYTOITEM (0x2e):** the up/down keys (including the number pad 8 and 2) move the selection. **WM_SETCURSOR/hover (0x20):** selects the choice under the pointer, beeps if the pointer is outside. **Left button (0x201):** posts command 2, which selects the highlighted choice. **WM_COMMAND (0x111):** command 1 (Enter) or 2 (a click) while no reply plays runs the choice (`1068:11da`: hide, unhide, destroy, assign, speak the line and the replies with subtitles, pick the next node), marks that speech is running (`DS:1db6`) and clears the list; while a reply plays, a click ends the wait early. **Right button (0x204/0x205):** ends the wait of a reply. **Mouse up (0x202):** inside the arrow areas scrolls the list by one choice. **Private message 0x400 (value 0x1ada):** the reply has finished: clears the speech flag, refills the list with `1068:1030`; with no node left it turns the beep back on, frees the conversation and ends the dialog; otherwise reselects the old position.
**Calls:** `1068:1030`, `1068:11da`, `1068:0000`, `1008:0f86`, `1078:1238`, `10a8:0092`, `1080:0890`, `1080:0ad6`, `1080:0d56`, `1090:0000`, list box, GDI and WinG calls.
**Yields / blocks / timing:** Modal; the speech replies run through the sound queue and the 0x400 message ends them.
**Edge cases:** The key codes 0x25 to 0x28 and the number pad move the choice; the list control is a normal owner-drawn list box (messages 0x401 to 0x41b).
