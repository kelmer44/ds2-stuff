# 10d8:0052 inferred_compare_name12
Status: understood · Cluster: resource layer · Convention: cdecl far, two far pointers

**Purpose (confirmed):** Compare two index entries or keys by their 12-byte name field (confirmed).
**Inputs:** `[bp+6..8]` far pointer A and `[bp+a..c]` far pointer B, each pointing 2 bytes before a name (at the start of a 22-byte entry, or at key minus 2).
**Outputs / state written:** Returns the sign-extended 8-bit difference `A[i] - B[i]` of the first differing byte over bytes 2 to 13, or 0 when all 12 bytes match. Huge-pointer carries are handled when the offset wraps.
**Calls:** `10d0:029e` stack probe.
**Yields / blocks / timing:** none
**Edge cases:** The difference is truncated to 8 bits before sign extension; with ASCII names this equals the sign of the comparison. In the table search A is the key and B the entry, so a positive result means the key sorts after the entry.
**Evidence:** `re/export/fn/10d8_0052.asm`; the sort order of all 9291 entries is plain unsigned byte order (checked in Python).
