# 1088:051c inferred_find_entry
Status: understood · Cluster: resource layer · Convention: cdecl far (table far pointer, key near pointer)

**Purpose (confirmed):** Find the index entry for a normalised 12-byte name in the sorted entry table (confirmed).
**Inputs:** `[bp+6..8]` far pointer to the glue table (the structure at `DS:275e`, see `STRUCTS.md`); `[bp+a]` near pointer to the key in the data segment.
**Outputs / state written:** Returns a far pointer to the 22-byte entry, or 0 (DX:AX) when the name is not in the table.
**Calls:** `10d8:0052` compare, `10d0:029e` stack probe.
**Yields / blocks / timing:** none
**Edge cases:** Search: `lo = 0`, `hi = count - 1`; while `hi - 1 > lo`: `mid = (lo + hi) / 2`; compare key with entry `mid`; equal returns it; key greater sets `lo = mid`, key smaller sets `hi = mid`. After the loop entry 0 is tested, then entry `count - 1`; if neither matches the result is 0. With 2 or fewer entries only those two tests run. The 22-byte stride uses huge-pointer arithmetic (selector step `__AHSHIFT`).
