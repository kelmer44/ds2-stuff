# 10b8:0368 inferred_lz_decompress_block (entry `10b8:0370` after a stack-probe prologue)
Status: understood · Cluster: resource layer · Convention: pascal far, callee pops 12 bytes (`retf 0xc`); 32-bit code segment, 16-bit stack frame.

**Purpose (confirmed):** decode one block of an LZ-style compressed glue stream (format in `STRUCTS.md`).

**Inputs:** (pushed first to last) `[bp+6]` int16 input byte budget; `[bp+8..a]` far source pointer (offset, selector); `[bp+c]` u32 destination offset, `[bp+10]` destination selector.
**Outputs:** `eax` = bytes written (`end - start`). Writes decoded bytes to `es:dest`, contiguous with earlier output when the caller passes the running end pointer.
**Calls:** none.
**Yields / blocks / timing:** none.
**Algorithm:** `count = 0; loop { flags = *src++ (dh = 0xff sentinel); for each of 8 flags (LSB first): flag 1 -> copy 2 bytes; flag 0 -> w = word at src, src += 2, n = (w&15)+3, d = (w>>4)+1, copy n bytes from dst-d in dword steps (8, 8, 2), dst += n; after the group count += 17; if count >= budget return }`.
**Edge cases:** the group counter is a signed 16-bit compare (`jge`), so budgets above 0x7fff are treated as negative. Overlapping matches with distance 1 to 3 read unwritten bytes (see `STRUCTS.md`). No bounds checks on source or destination.
**Evidence:** disassembly with capstone in 32-bit mode (the NE segment flag `0x2c50` and the 66/67 prefixes show USE32 code); Ghidra mis-decodes this segment as 16-bit code. `re/tools/ne_segments.py dis 10b8:0368 0xf0 --use32`.
**Port:** none yet.
**Validation:** an independent Python model (`re/tools/glue_probe.py`, `glue_verify.py`) decodes all 85 compressed glue files; every decoded directory matches the GFILE.HDR entries for that file and every BMP entry starts with `BM`. This checks the algorithm against data, not the machine code against the port (`emu-compared` is not reached).
**Open questions:** how the caller sizes the last block (`10d0:055c` and `10d0:052a` involved); whether any compressed file needs the unwritten-read behaviour for real content (none seen).
