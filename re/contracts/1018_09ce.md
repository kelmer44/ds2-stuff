# 1018:09ce inferred_write_save_file
Status: understood · Cluster: dialogs · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Write the current game to the save file of a slot.
**Inputs:** The slot number (0 to 9).
**Outputs / state written:** Creates `DS2SGnn.SAV` and fills a memory block with 16-bit words: the game mode `DS:007c`, the player position `DS:3cae`, `DS:3cb0`, the facing `DS:8e3c`, four words that are not set, the cursor mode `DS:770e`, the game speed `DS:0046`, the marker `0xFADA`, the values of all game variables (`DS:5e14`, count `DS:5cda`), 50 words that say whether each of the 50 per-room blocks exists, then each existing block (a word count followed by that many words), and the marker `0xFADA` again. The block is scrambled with `1018:05c0` (key `0x4E16A83F`) and written. The dialog-up flag is set during the write.
**Calls:** `1018:05c0`, `1090:0000`, `1090:0068`, `OpenFile`, `_hwrite`, `_lclose`, `wsprintf`.
**Yields / blocks / timing:** none
**Edge cases:** The length written is rounded down to an even number of bytes. In the sample save `DS2SG00.SAV` (832 bytes) the file holds 330 variables and one per-room block.
**Evidence:** `re/export/fn/1018_09ce.c`; layout checked by unscrambling `DS2SG00.SAV`: the marker is at word 10 and at the end, the 330 variables and the single flagged block account for every word.
