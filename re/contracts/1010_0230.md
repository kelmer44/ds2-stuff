# 1010:0230 inferred_confirm_quit
Status: understood · Cluster: dialogs · Convention: cdecl far, caller cleans

**Purpose (confirmed in outline):** Ask whether to quit the game (offering to save first when it is safe) and start the shutdown.
**Inputs:** The owner window.
**Outputs / state written:** Sets the dialog-up flag. If `DS:0048` is non-zero it quits at once. Otherwise, while a room is changing (`DS:610e`) nothing happens. If the game is busy (menu mode `DS:007c` = 2, a video, a cut-scene, a pending action, or `LastAction` not 4) it asks "¿Estás Seguro?" (yes/no) and quits on yes. When idle it asks "¿Quieres guardar la partida antes de salir?" (yes/no/cancel): yes opens the save dialog (`1018:0566`) and then quits, no quits, cancel does nothing. Quitting calls `10a8:0b7e` and posts the close message to the window.
**Calls:** `1018:0566`, `1060:0b00`, `10a8:0b7e`, `MessageBox`, `PostMessage`.
**Yields / blocks / timing:** none
**Edge cases:** Closing the save dialog without saving still quits (the answer was yes to saving, but the result is not checked).
