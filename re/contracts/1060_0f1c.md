Status: understood · Cluster: game variables · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Parse up to n signed decimal numbers into 32-bit values.
**Inputs:** A near pointer to the text, a far pointer to the output (32-bit values) and the maximum count.
**Outputs / state written:** Skips spaces, commas, CR and LF, reads an optional `-` and the digits as a 32-bit number, multiplies by the sign and stores it; stops at the end of the text or after n numbers. The unread rest of the output is filled with zeros. Returns how many numbers were read.
**Calls:** `10d0:052a` (32-bit multiply).
**Yields / blocks / timing:** none
**Edge cases:** A character above `9` ends a number; a stray `-` in the middle is not handled.
