# 1000:12be inferred_handle_key
Status: understood · Cluster: main window and input · Convention: cdecl far, caller cleans

**Purpose (confirmed in outline):** Handle one key press for the main window: pointer movement from the keyboard and the function keys.
**Inputs:** The window, the virtual-key code, the two halves of the key message's `lParam`, and a flag (`DS:0ad4`) that is non-zero while a key is being held. Called from `WINPROC` on key-down when no video plays (`DS:0368` is 0).
**Outputs / state written:** Held keys do nothing except the pointer-movement keys. **Pointer:** cursor keys, number-pad 8/2/4/6 and the letters I/K/J/L move the pointer by the step `DS:006c` (clamped to 640 by 480, kept in `DS:3c54`, `DS:3eb0`) and raise the step by 2 up to 10. **Other keys:** Enter refreshes the hover state and, while a cut-scene wait counter `DS:008a` is above 5, ends it and repaints the screen; Esc calls `1010:0230`; Space steps the cursor mode `DS:770e` through 0, 1, 2; A opens the about box (not while `DS:610e` is set); D toggles digital sound; M toggles music; P pauses the game (stops MIDI, deactivates WaveMix, writes "Pausa Juego" in white Arial in the middle of the screen) and a second P resumes and repaints; F1 opens the help file `dsii.hlp`; F2 calls `1010:0336`; F6 `1010:011e`; F7 `1018:01fa`; F8 `1018:0566` (only when idle with `LastAction` at 4); F9 stops the music and shows the picture routine `1000:19f2` or comes back from it; F11 cycles `DS:0046` through 5, 24 and 15; Num Lock is passed to the default window procedure.
**Calls:** `1000:1d1a`, `1000:1c36`, `1000:19f2`, `1010:011e`, `1010:0230`, `1010:0336`, `1018:01fa`, `1018:0566`, `1038:01e4`, `1060:0b00`, `1060:0b26`, `1078:1238`, `1080:038a`, `1080:041a`, `1080:049a`, `10a8:0042`, `10a8:0a1e`, Windows dialog, GDI and MCI calls.
**Yields / blocks / timing:** none
**Edge cases:** Most function keys are ignored while the room is changing (`DS:610e`). Which window message produced the key (key-down versus a mapped menu key) is decided by `WINPROC`.
**Evidence:** `re/export/fn/1000_12be.c`; the call at `WINPROC` (`1000:0938`) and the inventory dialog (`1008:0516`); strings at `DS:0c22..0cc8` (`aboutbox`, `dsii.hlp`, `Pausa Juego`).
