# 10a0:00be inferred_atan2
Status: understood · Cluster: math · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Angle of the vector (x, y) in the 1024-unit circle (confirmed).
**Inputs:** `[bp+6]` x, `[bp+8]` y (signed 16-bit).
**Outputs / state written:** Returns 0xffff for (0, 0). Otherwise takes the smaller over the larger absolute value as a ratio scaled by 256, looks the angle up in the byte table at `DS:266c` (257 bytes, round(atan(i/256) * 512 / pi); checked: 0, 1, 1, 2, ..., 71 at i = 120, 128 at i = 256) and mirrors it into the right octant and quadrant. Result 0 to 0x400.
**Calls:** `10d0:0490` (32-bit divide).
**Yields / blocks / timing:** none
**Edge cases:** The ratio is rounded up when the remainder byte exceeds 0x80. Equal absolute values give 0x80 (45 degrees) before the quadrant fix-up. The angle 0x400 and 0 are the same direction.
**Evidence:** `re/export/fn/10a0_00be.c`; table values compared with a real arctangent in Python.
