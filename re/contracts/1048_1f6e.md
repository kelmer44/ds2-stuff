# 1048:1f6e inferred_load_room
Status: understood · Cluster: script and rooms · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Read a room file and build the room record (confirmed for the header keys and the dispatch; the section readers it calls are separate functions).
**Inputs:** The room number is on the stack (formatted into `ROOM%04d.DAT`).
**Outputs / state written:** Loads the file (`inferred_load_file_or_plain`, size by `inferred_get_file_size`), resets the read position, allocates and zeroes the room record (0x15d8 bytes) and stores its far pointer at `DS:6892/6894`. Then reads lines with `inferred_next_room_token` until `ENDID=` (code 99) and handles each: `LOCALVAR=` registers a room-local variable; `ENTRYSTART=` allocates the entry-list head (0x95 bytes, at room +2/+4) and calls `1048:19fc`; `MUSICSTART=` calls `1048:18fe`; `MIRRORSTART=` calls `1048:156a`; `PALETTESTART=` calls `1048:17ea`; `SPRITESTART=` calls `1048:114a`; `BACKDROP=` copies the name to room +6; `SCALEFACTOR=` parses two numbers into room +0x33 and +0x35 (the third number is ignored); `OBJXY=` parses four numbers into room +0x2b to +0x32 (the room's clip rectangle); `WALKMAP=` copies the name to room +0x3d and parses two further numbers into room +0xf4a and +0xf4c (set to 0 and 10 when fewer than two are given). Frees the file buffer and returns the room record.
**Calls:** `1098:0326`, `1088:0892`, `1090:0000`, `1090:0068`, `1048:0b54`, `1048:114a`, `1048:156a`, `1048:17ea`, `1048:18fe`, `1048:19fc`, `1060:048e`, `1060:0062`, `1060:0c44`, `lstrcpy`.
**Yields / blocks / timing:** none
**Edge cases:** A key outside the list is ignored (the lexer returns 0). An `OBJXY=` with fewer than four numbers leaves the rest 0 (the number parser zero-fills). `SCALEFACTOR=` with two numbers works; all 83 shipped rooms give three. The room file name uses four digits (`ROOM0101.DAT`).
**Evidence:** `re/export/fn/1048_1f6e.c` and `.asm` (destinations read from the assembly); checked against all 83 room files.
