# 1078:06f4 inferred_draw_sprite_lists
Status: understood · Cluster: graphics and sprites · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Draw all sprites that touch a rectangle, back to front (confirmed).
**Inputs:** `[bp+6..8]` scene far pointer, then x, y, width, height of the rectangle, and a depth threshold.
**Outputs / state written:** Sorts list 0 (`inferred_sort_sprite_list`), then draws every non-null sprite of list 0 for which `threshold <= sprite +0x30` or `sprite +0x12 == 0`. Then sorts list 1 and draws every sprite in it with no condition. So list 1 is always drawn on top of list 0.
**Calls:** `1078:05be`, `1078:0454`.
**Yields / blocks / timing:** none
**Edge cases:** A threshold of 0 draws everything (all anchor y values are positive); the single-sprite updates pass the moving sprite's own y. The meaning of `sprite +0x12` is not known: sprites with `+0x12 == 0` ignore the threshold.
