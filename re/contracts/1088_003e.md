# 1088:003e inferred_load_glue_file
Status: understood · Cluster: resource layer · Convention: cdecl far (table far, name far, destination far)

**Purpose (confirmed):** Load a whole glue file into memory, decompressing it, and remember where it is so later lookups use the memory copy (confirmed).
**Inputs:** `[bp+6..8]` far pointer to the glue table; `[bp+a..c]` far pointer to the glue file name; `[bp+e..10]` optional far pointer to a preallocated destination (0 to allocate).
**Outputs / state written:** Finds the glue by comparing the name with the table's name list (`lstrcmpi`). Returns without work when the glue already has a memory pointer. Builds the path from the directory chosen by the per-glue byte; opens it (failure: `OutputDebugString`, sets `DS:0048` = 1 and calls `1010:0230`). Reads the first 2048 bytes; the u32 at `+0x7fc` plus `0x80` is the size to allocate (or the given destination is used). Stores the destination pointer in the glue's slot, then loops: a full block (2048 bytes read) is decoded with budget `0x7f8`; a short last block is zero-filled up to `((n + 16) / 17) * 17` and decoded with that budget. The decoder's byte count advances the destination offset. When a full block was decoded it reads the next 2048 bytes. At the end it frees the 2 KB buffer and closes the file.
**Calls:** `1090:0000`, `1090:0068`, `10b8:0368`, `10d0:055c`/`10d0:052a` (32-bit divide and multiply by 17), `OpenFile`, `_hread`, `_lclose`, `lstrcmpi`, `lstrcpy`, `lstrcat`, `OutputDebugString`, `1010:0230`.
**Yields / blocks / timing:** none
**Edge cases:** A glue file shorter than 2048 bytes is not handled specially. The destination buffer gets 128 spare bytes beyond the decoded length. The decoder writes through a selector with a limit above 64 KB and a 32-bit offset (the reason it lives in a 32-bit segment).
