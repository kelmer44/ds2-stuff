# 1018:05c0 inferred_xor_scramble
Status: understood · Cluster: dialogs · Convention: cdecl far, caller cleans

**Purpose (inferred):** Scramble or unscramble a buffer by XOR with a running 32-bit key (used on save files).
**Inputs:** A far pointer to the buffer, its length in bytes (32-bit) and a 32-bit starting key.
**Outputs / state written:** For each group of 4 bytes: key = key + (key shifted right by 7), then the 4 bytes are XORed with the key. Bytes after the last whole group are left alone. The key does not depend on the data, so the same call undoes itself.
**Calls:** none
**Yields / blocks / timing:** none
**Edge cases:** The decompiler shows the 32-bit shift as seven 16-bit steps; the reading above comes from that listing and not yet from a test against a real `.SAV` file.
**Evidence:** `re/export/fn/1018_05c0.c`; callers `1018:0648` (load, `1018:06e9`) and `1018:09ce` (save, `1018:0c05`).
