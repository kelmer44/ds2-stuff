# 1088:0892 inferred_get_file_size
Status: understood · Cluster: resource layer · Convention: cdecl far (glue table far pointer, name near pointer)

**Purpose (confirmed):** Return the size of a named resource, or of a plain file when the index is not loaded yet (confirmed).
**Inputs:** `[bp+6..8]` far pointer to the glue table, `[bp+a]` near pointer to a name.
**Outputs / state written:** If the 'loaded' word at table offset 4 is zero: opens the file with that name and returns its length (`_llseek` to end). Otherwise: normalises the name into `DS:3770`, finds the entry and returns its size (u32 in DX:AX); if not found it prints the two strings with `OutputDebugString` and returns 0.
**Calls:** `1088:04c8`, `1088:051c`, `OpenFile`, `_llseek`, `_lclose`, `HMemCpy`, `OutputDebugString`.
**Yields / blocks / timing:** none
**Edge cases:** The size is the size in the (decompressed) stream, which is also the size of the resource itself. No error box is shown when the file is missing.
