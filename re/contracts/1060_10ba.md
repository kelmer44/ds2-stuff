# 1060:10ba inferred_load_game_vars
Status: understood · Cluster: game variables · Convention: cdecl far, caller cleans

**Purpose (confirmed):** Load the variable list from `GameVar.IDX` and check that it is sorted (confirmed).
**Inputs:** `[bp+6]` near pointer to the file name (`GameVar.IDX`).
**Outputs / state written:** Loads the file with `inferred_load_file_or_plain`, then reads lines with `inferred_read_idx_line`: each line `NAME=value` fills the next 25-byte slot (`DS:05f0 + 25 * i`) and the next value word (`DS:5e14 + 2 * i`). It stops after the line whose name equals the end marker `zzzLast`. The count (`DS:5cda`) is the number of lines read, including that one. Then every name must not sort before its predecessor (case-insensitive), otherwise it shows "programmer error: game variable (%d) not sorted!". Frees the file.
**Calls:** `1098:0326`, `1060:1040`, `lstrcmpi`, `_wsprintf`, `1098:0248`, `1090:0068`.
**Yields / blocks / timing:** none
**Edge cases:** The end marker is the string at `DS:1d74`. Names longer than 24 characters would overflow the slot; no check. Only the first variable list is read here; per-room local variables are handled elsewhere.
